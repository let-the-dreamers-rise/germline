Germline records each change the instant it takes effect and anchors the log on BOT Chain, where anyone can check it. From a file's GitHub history

A public GitHub repo and the config file inside it (JSON, or any text file such as a prompt). Germline reads the file's commit history and records each change: what moved, who committed it, and the commit message as the reason.
Or record a change by hand

Fully automatic, with no browser open

The same thing runs in your repo's CI: on every merge that touches the config, the Germline GitHub Action records the change and anchors it on BOT Chain. Add a funded key as the GERMLINE_ANCHOR_KEY secret and this workflow:
on: { push: { branches: [main] } }
concurrency: germline
permissions: { contents: write }
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: let-the-dreamers-rise/germline@main
        with:
          anchor-key: ${{ secrets.GERMLINE_ANCHOR_KEY }}
          rpc: https://rpc.botchain.ai
